# 💌 Letters for S

A simple and heartfelt web application built with **Flask** that allows users to write and read personal letters through a clean and elegant interface. Built with **Python** on the backend and **HTML, CSS, and JavaScript** on the frontend.

---

## ✨ Features

- 💌 Write and read personal letters
- 🎨 Clean and minimal user interface
- ⚡ Flask-powered backend
- 📄 Dynamic HTML rendering using Jinja2
- 📂 Well-structured and easy-to-understand codebase

---

## 🛠️ Tech Stack

**Backend**
- Python
- Flask

**Frontend**
- HTML5
- CSS3
- JavaScript

**Template Engine**
- Jinja2

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

Clone the repository:

```bash
git clone https://github.com/unnatissrivastava/letters-for-s.git
cd letters-for-s
```

Create a virtual environment (recommended):

**Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux**
```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
